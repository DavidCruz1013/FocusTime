FocusTime

Aplicación iOS para organizar sesiones de concentración, descansos, metas diarias y registro manual de aplicaciones. Desarrollada por el Grupo #4 de Normas y Estándares Internacionales, Universidad Tecnológica de El Salvador.

Documento final (PDF) Código fuente en GitHub

Funciones principales

  • Sesiones de concentración con pausa, reanudación y finalización.
  • Descansos opcionales y avisos locales.
  • Metas diarias y progreso semanal.
  • Registro manual de aplicaciones.
